# Roadmap XP

One XP route for Dungeons & Dragons Online, from level 1 to 36, for a character that reincarnates. It shows the next quest, where to pick it up, and a torch that moves along the route as you mark quests done.

**Live site: https://ddo-roadmap-xp.pages.dev**

## Is the link safe?

This repository is the full source of the site. Everything the site runs is here:

- **No download, no launcher.** It is a static website with a few small API endpoints (`functions/`). Nothing is installed on your computer.
- **No account needed.** "Try it without an account" keeps your progress in your browser's `localStorage`. Nothing is sent to the server.
- **Discord sign-in is optional.** It is only for keeping your progress across devices. It asks Discord for the `identify` scope alone ([`functions/api/auth/login.js`](functions/api/auth/login.js)), so the site receives your Discord ID, username and avatar. It never sees your email, your servers or your messages, and it cannot post anything.
- **What is stored** ([`schema.sql`](schema.sql)): your Discord ID, username and avatar, your characters (name, life number, entry level, VIP, expansions), and which quests you marked done or skipped. Session cookies are stored only as a SHA-256 hash.
- **Your data stays yours.** You can export everything as JSON and delete your account from the Account page.
- **Strict headers.** The Content Security Policy only allows the site's own scripts ([`src/_headers`](src/_headers)). The site uses no analytics, trackers or third-party scripts.

## What it does

- **One route, 1 to 36.** It is built for reincarnated characters, with entry points at level 1, 15 or 20, and never a first-life route.
- **Filtered to your access.** Set your life number, VIP status and owned expansions, and the route skips what you cannot run.
- **Done, skip, undo.** The card shows the next quest. Press <kbd>D</kbd> or click Done to move on. The route view shows every step.
- **"The Ascension" map.** An original illustrated map of levels 1 to 36, with the torch on your current level.
- **The guide.** It explains the route chapter by chapter and cites its sources.

## Stack

- **Static site** generated by [`build.mjs`](build.mjs) from `src/` and `data/`. It has no framework and uses plain JS modules. The map is an SVG generated at build time ([`map.mjs`](map.mjs)).
- **Hosting and API:** [Cloudflare Pages](https://pages.cloudflare.com/) with Pages Functions ([`functions/`](functions)).
- **Database:** [Cloudflare D1](https://developers.cloudflare.com/d1/) (SQLite).
- **Sign-in:** Discord OAuth2 with the `identify` scope.

## Run it yourself

You need Node 20+, a Cloudflare account, and a Discord application if you want sign-in.

```bash
npm install
npm run build          # writes the static site to public/
```

**Local dev with the API:**

1. Create the local database and start the server:
   ```bash
   npm run db:init:local
   npm run dev            # http://localhost:8788
   ```
2. For a local Discord sign-in, create a git-ignored `.dev.vars` file:
   ```
   DISCORD_CLIENT_SECRET=...
   APP_ORIGIN=http://localhost:8788
   ```
3. In the Discord Developer Portal, add `http://localhost:8788/api/auth/callback` as a redirect.

**Your own deployment:**

1. Create a D1 database with `npx wrangler@3 d1 create ddo-roadmap`, and put its `database_id` in [`wrangler.toml`](wrangler.toml). Then apply the schema with `npm run db:init`.
2. Create a Discord application. Under OAuth2, add the redirect `https://<your-domain>/api/auth/callback`.
3. In `wrangler.toml`, set `DISCORD_CLIENT_ID` and `APP_ORIGIN`. Also set `SITE` at the top of `build.mjs`, which is used for canonical URLs and the sitemap.
4. Set the secret:
   ```bash
   npx wrangler@3 pages secret put DISCORD_CLIENT_SECRET --project-name <your-project>
   ```
5. Deploy with `npm run deploy` (change `--project-name` in `package.json`).

`scripts/` holds optional dev tools: Lighthouse runs and the share-image and icon generators. They need a Playwright Chromium, or Chrome or Edge.
